# 08 · Miras de las armas
Modelos de mira para el banco de Tino (mejora "Mira"): punto rojo para pistola, mira holográfica para escopeta/fusil, mira telescópica
para francotirador. Usa las armas de esta carpeta para tamaño y estilo. Guarda en `imageassets\blender\armas\Mira_<Tipo>.fbx`,
pivote en la base de montaje.
