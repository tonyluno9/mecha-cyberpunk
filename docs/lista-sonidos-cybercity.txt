LISTA COMPLETA DE SONIDOS — CYBERCITY
18-nov-2026

Cómo leerla:
- Cada línea es un sonido aparte. El código entre corchetes es el nombre sugerido del archivo (ej. ARM_W06_DISPARO.wav).
- "(x3)" o "(x4)" = hacer 3 o 4 variantes del mismo sonido para que no se repita igual (ej. _01, _02, _03).
- "(loop)" = sonido que se repite sin corte (motor, ambiente, lluvia).
- "(cerca / lejos)" = dos versiones: una fuerte y nítida, otra lejana con eco (para cuando pasa a distancia).
- Ya hay 288 sonidos en Assets/Arte/Audio. Una sesión puede cruzar esta lista con lo que ya existe y marcar lo que falta.
