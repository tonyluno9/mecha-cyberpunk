# CYBERFIX — Piezas de interfaz (para WaveSpeed)
Estilo aprobado: los mockups de HUD y menú del 31-oct (marcos angulares con esquinas cortadas, naranja neón como acento, turquesa y magenta de apoyo, paneles oscuros translúcidos, look pintado que combina con el low-poly).
Nano Banana 2.1, UNA generación por prompt, 1K. Cada prompt es completo y no depende de los otros.
Todas (menos la 14) van sobre fondo gris liso para quitarle el fondo después. Guardar en `imageassets/ui/<código>.png`.
Después: Claude Code les quita el fondo (rembg o similar), recorta las hojas en piezas sueltas y arma la interfaz en Unity con las fuentes Teko (títulos y números) y Rajdhani (texto).
