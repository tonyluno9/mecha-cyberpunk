# CYBERFIX — Escenas de referencia de la ciudad (para WaveSpeed)
Para la sesión de Claude con WaveSpeed: Nano Banana 2.1, UNA generación por prompt, 1K, 16:9. Cada prompt es completo y no depende de los otros.
Guardar como `docs/referencias-ciudad/<nombre>.png` en la carpeta del juego. Después estas imágenes se le pasan a Claude Code para rehacer la iluminación y el acomodo de la ciudad con los assets que ya existen.

Todos los prompts describen solo cosas que ya tenemos en el juego: fachadas de planta baja con cortinas metálicas y pisos altos con ventanas, cornisas, postes de luz, transformadores, mazos de cables, tinacos, aires acondicionados, basureros, tambos, huacales, puestos de tacos y de electrónica, letreros planos de neón, proyectores holográficos, pantallas verticales y gigantes, expendedoras, servidores callejeros, cargadores, cámaras corporativas, drones, barreras, carro viejo y carro cyberpunk, moto.
