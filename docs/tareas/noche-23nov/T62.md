# T62. Avisos del tutorial en una ventana central con 'Entendido'; máquina expendedora con ratón
Sesión: B

## Qué vio Tony
Los avisos del tutorial salen abajo y se quedan; el de prótesis se repite aunque ya lo hiciste (bug). En la máquina expendedora no se puede usar el ratón.

## Qué hacer
1. Cada aviso del tutorial sale en una ventana al CENTRO (estilo de la UI nueva) con el texto y un botón ENTENDIDO (clic o Enter); el juego se pausa mientras está abierto.
2. Cada aviso sale UNA sola vez: si ya se completó ese paso (prótesis ya activadas), no vuelve a salir. Se guarda en la partida.
3. Menú de la máquina expendedora: selección con ratón (pasar y clic para comprar) además del teclado.

## Cómo comprobar
Hacer el tutorial: cada aviso una vez, al centro, con Entendido; comprar papitas con el ratón.

## Estado
pendiente
